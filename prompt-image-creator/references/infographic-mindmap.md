## 1. Infographic

### Kích thước theo mục đích sử dụng

| Mục đích | Tỉ lệ | Resolution | Ghi chú |
|----------|-------|------------|---------|
| **Web/Pinterest** | 1:3 (dọc) | 2048x6144 | Long scroll, mobile-friendly |
| **Instagram Post** | 1:1 | 2048x2048 | Square infographic |
| **Instagram Carousel** | 4:5 | 1640x2048 | Multi-slide story |
| **Facebook Post** | 1:1 hoặc 4:5 | 2048x2048 | Feed optimized |
| **LinkedIn** | 1.91:1 hoặc 1:1 | 2400x1256 | Professional |
| **Print A4** | 1:1.41 | 2480x3508 (300DPI) | Báo cáo, tài liệu |
| **Print A3** | 1:1.41 | 3508x4961 (300DPI) | Poster lớn |
| **Tài liệu nội bộ** | 1:2 | 2048x4096 | Vừa phải |

### 8 phong cách infographic chính

| Style | Đặc điểm | Phù hợp |
|-------|----------|---------|
| **Minimalist Flat** | Phẳng, ít chi tiết, nhiều khoảng trắng | Báo cáo, công nghệ, tài chính |
| **Isometric 3D** | Phối cảnh isometric, tech-feel | IT, startup, e-commerce |
| **Hand-drawn/Sketch** | Vẽ tay, doodle, casual | Giáo dục, sáng tạo, blog |
| **Modern Gradient** | Gradient mesh, vibrant, trendy | Marketing, social media |
| **Corporate Clean** | Chuyên nghiệp, blue tones, lưới | B2B, doanh nghiệp lớn |
| **Vintage/Retro** | Tông cũ, paper texture, classic | Lịch sử, truyền thống |
| **Data-heavy** | Nhiều biểu đồ, số liệu | Báo cáo nghiên cứu, kinh tế |
| **Story-driven** | Narrative flow, character | Cause/social, giáo dục |

### 10 cấu trúc Infographic phổ biến

1. **Step-by-step** — Quy trình từng bước
2. **Timeline** — Theo thời gian
3. **Comparison** — So sánh A vs B
4. **Hierarchy** — Phân cấp (kim tự tháp)
5. **Statistics-focused** — Tập trung vào số liệu
6. **Geographic/Map** — Theo vùng địa lý
7. **List/Listicle** — Danh sách đánh số
8. **Process Flow** — Quy trình có nhánh
9. **Anatomy/Diagram** — Cấu tạo, mổ xẻ
10. **Mixed/Magazine** — Kết hợp nhiều phần

## 2. Mindmap (Sơ đồ tư duy)

### Kích thước
- **Web/Digital**: 16:9 (3840x2160)
- **A4 ngang**: 1:1.41 (3508x2480, 300DPI)
- **A3 ngang**: 1:1.41 (4961x3508, 300DPI)
- **Vô cực canvas**: 2:1 hoặc 16:9 mở rộng

### 6 loại Mindmap chính

| Loại | Cấu trúc | Phù hợp với |
|------|----------|-------------|
| **Radial Map (Tỏa tròn)** | Trung tâm → tỏa ra các nhánh | Brainstorming chung, tổng quan |
| **Tree Map (Cây)** | Top-down, phân cấp rõ ràng | Cấu trúc tổ chức, phân loại |
| **Bubble Map (Bong bóng)** | Bong bóng kết nối linh hoạt | Concept maps, ý tưởng |
| **Flow Map (Dòng chảy)** | Tuyến tính có nhánh | Quy trình tư duy |
| **Fishbone (Xương cá)** | Nguyên nhân - kết quả | Phân tích vấn đề (Ishikawa) |
| **Concept Map** | Nhiều liên kết chéo | Học tập, kiến thức phức tạp |

### 5 phong cách thiết kế Mindmap

| Style | Đặc điểm |
|-------|---------|
| **Hand-drawn** | Vẽ tay, doodle, màu nước, mũi tên cong tự nhiên |
| **Modern Digital** | Clean lines, flat colors, geometric shapes |
| **Colorful Vibrant** | Mỗi nhánh một màu rực rỡ, eye-catching |
| **Minimalist BW** | Đen trắng tối giản, focus vào nội dung |
| **Tony Buzan Style** | Cong, organic, hình ảnh phong phú, classic mindmap |

## 3. Flowchart (Sơ đồ quy trình)

### Kích thước
- **Quy trình ngắn**: 16:9 ngang
- **Quy trình dài**: 9:16 dọc hoặc 1:2
- **Quy trình phức tạp**: A3 hoặc lớn hơn

### Ký hiệu chuẩn (BPMN/Standard)
- **Hình chữ nhật**: Hành động/Process
- **Hình thoi (Rhombus)**: Quyết định/Decision
- **Hình bầu dục (Oval)**: Bắt đầu/Kết thúc
- **Hình bình hành**: Input/Output
- **Mũi tên**: Hướng dòng chảy
- **Hình trụ**: Database
- **Hình tròn nhỏ**: Connector

### Prompt Template
```
Professional flowchart diagram for [process name],
clear top-to-bottom (or left-to-right) flow direction,
standard flowchart symbols: rectangles for processes, 
diamonds for decision points, ovals for start/end, 
parallelograms for input/output,
[number] main steps with [number] decision branches,
clean modern design with [color scheme: corporate blue / vibrant multi-color / minimalist mono],
arrows clearly indicating flow direction with proper spacing,
text inside shapes is concise and readable,
swim lanes if multi-department/role process,
white background with subtle grid or light gradient,
[16:9 horizontal / 9:16 vertical / A3 landscape] orientation,
4K resolution, presentation and print ready,
following industry-standard flowchart conventions
```

### Phong cách Flowchart

| Style | Mô tả |
|-------|-------|
| **Corporate Standard** | Blue & gray, formal, BPMN compliant |
| **Modern Tech** | Bright accents, rounded corners, gradient |
| **Hand-drawn** | Sketch style, casual, friendly |
| **Swim Lane** | Phân chia theo department/role |
| **Process Map** | Lean Six Sigma style, color-coded |

## 4. Timeline

### Kích thước
- **Horizontal timeline**: 21:9 hoặc 16:9 (cho web)
- **Vertical timeline**: 1:3 hoặc 1:4 (cho infographic)
- **Roadmap**: 16:9 (cho presentation)

### 5 loại Timeline

| Loại | Phù hợp |
|------|---------|
| **Linear (Đường thẳng)** | Lịch sử, biên niên sử |
| **Roadmap** | Kế hoạch dự án, chiến lược |
| **Gantt-like** | Quản lý tiến độ |
| **Vertical zigzag** | Câu chuyện, journey |
| **Circular** | Vòng đời, quy trình lặp |

### Prompt Template
```
Timeline infographic showing [topic] from [start year] to [end year],
[horizontal/vertical/zigzag/circular] layout,
[number] key milestones marked with prominent date markers,
each milestone featuring: date, event title, brief description, relevant icon or image,
connecting line/path with directional indicators,
color-coded by [time period / category / importance],
[style: modern minimalist / vintage classic / corporate / creative],
chronological flow clearly visible,
balanced spacing between events,
[color palette],
header with title and subtitle,
[16:9 / 1:3 / 21:9] aspect ratio,
4K resolution, presentation and printing ready
```

### Ví dụ
- **Lịch sử Việt Nam**: Vintage style, sepia tones, ancient map texture
- **Roadmap sản phẩm**: Modern tech, gradient timeline, milestone badges
- **Career journey**: Vertical zigzag, photo + description, growth arrow
